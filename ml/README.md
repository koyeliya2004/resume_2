# ML Model Training

This folder contains Kaggle notebook links and saved model files.

## Workflow
1. Train the overall score prediction model in Kaggle.
2. Download the saved `.pkl` model file.
3. Place it in `ml/saved_model/` folder.
4. The backend will load it from here for prediction.

## Files
- `saved_model/` → trained model files go here (not committed to git)
- `kaggle_notebook_link.txt` → link to your Kaggle training notebook
